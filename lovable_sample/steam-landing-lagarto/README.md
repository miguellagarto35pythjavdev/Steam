**Activity: Elective I (Software Development)**

## Purpose
This project is created solely for educational purposes to practice recreating a real-world webpage framework using HTML and CSS. It demonstrates semantic HTML, CSS layout, navigation, typography, image placement, and layouts for different screen sizes.

## Basic description
A visual recreation of Steam's Autumn Sale storefront as observed on October 7, 2026. Includes the Steam header, store navigation and search, original Autumn Sale banner, featured games, special offers, category links, game lists, sign-in links, and legal footer. It is a selected recreation, not a complete or pixel-perfect copy of every Steam page.

The main framework is plain HTML and CSS. A small optional JavaScript block inside index.html supports the carousel, local game filtering, and tabs; there are no external JavaScript libraries or dependencies. Links to products, sign-in, support, and other services open the real Steam/Valve websites. This project itself does not collect credentials, process purchases, or connect to Steam accounts.

## How to open
1. Extract the ZIP file.
2. Keep index.html, style.css, and the assets folder together.
3. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).

No installation or build step is needed. Images and styles are stored locally and work offline; external Steam links require an internet connection.

## Files
- index.html — semantic webpage structure and optional inline interactions.
- style.css — all visual layout and screen-size styles.
- assets/ — locally stored original images and logos.
- README.md — project description, educational disclaimer, image references, and the original prompt.
