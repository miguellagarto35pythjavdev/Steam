# Steam storefront — standalone HTML and CSS

Open `index.html` in a modern browser. No installation, compilation, server, React, Tailwind, or JavaScript is required.

## Contents
- `index.html`: semantic page markup and native controls.
- `styles.css`: colors, layout, responsive rules, CSS-only featured selector and game tabs.
- `assets/`: bundled Steam logo, game artwork, and screenshots, available offline.

## Interactions
- Featured-game dots switch between three games using HTML radio inputs and CSS.
- Game tabs change the visible lists using HTML radio inputs and CSS.
- Store menus use native HTML details/summary.
- Search submits to Steam's official search page (internet connection required).
- Game cards, category links, sign-in, and purchase links open official Steam pages.

Prices and offers are illustrative sample values, not live Steam pricing. Review and upcoming labels are sample content. This is an unofficial visual recreation, not affiliated with Valve. Artwork and trademarks belong to their respective owners.

The existing Lovable app is unchanged. This archive is a separate standalone copy.
